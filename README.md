# Local Kanban

A fast, private Kanban desktop app for Windows. No account, no cloud, and no subscription—your boards and attachments stay in a folder you choose.

## [Download for Windows](https://github.com/grayfvll01/local-kanban-board/releases/latest/download/Local-Kanban-Setup.exe)

Windows 10/11 · 64-bit · Installer `.exe`

Open the app, choose a vault folder, and start organizing. The latest installer is always available from the link above.
