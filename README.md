# Local Kanban

A fast, private Kanban board for Windows. No account, no cloud, no subscription. Your boards, notes, and attachments stay in a folder you choose.

### [⬇ Download for Windows](https://github.com/grayfvll01/local-kanban-board/releases/latest/download/Local-Kanban-Setup.exe)

Run `Local-Kanban-Setup.exe`, choose a folder for your vault, and start planning. No admin rights needed, and the app tells you when a new version is ready so you can update with one click.

- **Private** — everything lives in your vault folder. The only network request is an optional update check.
- **Offline** — works without an internet connection.
- **Safe** — automatic daily backups, one-click restore, and JSON, Markdown, and CSV export.
- **Yours to style** — 11 themes in light and dark, plus compact and minimal layouts.
- **Keyboard-friendly** — every drag action has a keyboard and menu alternative.

> Windows may show a SmartScreen notice because the installer isn't code-signed yet. Select **More info → Run anyway**.
