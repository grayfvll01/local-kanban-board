# Using Local Kanban

Launch Local Kanban, choose a vault folder, then create boards, columns, and tasks.

- **Tasks:** select a task to edit its title, notes (Markdown), tags, priority, due date, color, and attachments. Paste or drop images into the notes to attach them.
- **Moving tasks:** drag a task, use its ••• menu, or focus it and press Alt with an arrow key.
- **Columns:** use a column's ••• menu to rename it, set a WIP limit, move it, or delete it.
- **Search and filters:** Ctrl+K searches titles, notes, and tags. Filter by tag, priority, due date, or column.

## Backups

A backup of your data is saved automatically once a day in the vault's `backups` folder, and the 10 most recent are kept. A backup is also made before every import or restore, so either can be undone. Open **Settings → Backup and restore** to back up now or restore.

## Updates

Local Kanban checks for a new version shortly after it starts. When one is available, select **Update** in the status bar. You can turn automatic checks off in **Settings → Updates**.
